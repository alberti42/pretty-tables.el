#+title: A field guide to the Northern Marches

An example document for =pretty-tables-for-org-mode=. The guild, the
places and the creatures are invented; the table is shaped like real
ones, where most cells link to other documents. It is wider than
=fill-column=, and its cells hold one or two links each. The second
table holds LaTeX formulas, which =latex-to-svg-for-org-mode= draws as
images.

The linked files are not included, so the links do not open anything.
They are not needed to show the problem: =org-table-align= pads each
cell to the width of the visible text, so the raw table is aligned, but
each row is wider than the window. This package draws the table no wider
than =fill-column=, with the cells word-wrapped.
